## Tentang Aplikasi

Monitoring Spbu adalah aplikasi untuk memonitor stok yang ada di SPBU. terdapat banyak fitur yang diantaranya adalah

-   Perencanaan dan Pembelian BBM
-   Penerimaan BBM
-   Penyimpanan dan Monitoring Dombak
-   Pengelolaan Aset dan Fasilitas
-   Absensi Pegawai menggunakan QR Code, Location, dan Selfie Camera
-   Penjadwalan Kerja
-   Penerbitan Surat Menyurat
-   Setoran Ke Bank

Aplikasi ini dibuat untuk menyesuaikan kebutuhan di SPBU Bernah.
